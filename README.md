# NeuroNexus Internship Form

This project is an internship registration form that allows users to input their details like full name, contact information, address, company name, email, department, and gender.

## Features

- **Personal Information**: Capture user's full name, phone number, and address.
- **Company Details**: Capture company name and department selection.
- **Gender Selection**: Options to select gender.
- **Responsive Design**: The form adapts to different screen sizes.

## Technologies Used

- HTML
- CSS
- Google Fonts (Poppins)
